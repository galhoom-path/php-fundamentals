## Interview Question

What is the difference between echo and print?

## What The Interviewer Is Testing

Whether you know the basic output constructs and their small differences.

## A Strong Answer Should Cover

- Both are language constructs that output text, not real functions.
- `echo` can take several comma-separated values and returns nothing.
- `print` takes one value and always returns 1, so it can be used inside an expression.

## Practice Task

Write two lines that output the same sentence, one with `echo` and one with `print`, and explain the return value.
