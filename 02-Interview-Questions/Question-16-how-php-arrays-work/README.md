## Interview Question

How do PHP arrays work, and what is the difference between indexed and associative arrays?

## What The Interviewer Is Testing

Whether you understand that a PHP array is an ordered map.

## A Strong Answer Should Cover

- A PHP array is an ordered map: every value has a key, and insertion order is kept.
- Indexed arrays use integer keys; associative arrays use string keys.
- The same array can mix both kinds of keys, and arrays can be nested.

## Practice Task

Model one customer with an associative array and a list of customers with an indexed array of those arrays.
