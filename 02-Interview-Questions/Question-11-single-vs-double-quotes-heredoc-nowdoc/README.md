## Interview Question

What is the difference between single quotes, double quotes, heredoc, and nowdoc?

## What The Interviewer Is Testing

Whether you can choose the right string syntax for the job.

## A Strong Answer Should Cover

- Single quotes output text almost exactly as written; variables are not replaced.
- Double quotes and heredoc replace variables and understand escape sequences such as `\n`.
- Nowdoc is the multi-line version of single quotes: nothing is replaced.

## Practice Task

Write the same greeting with a variable in all four forms and state which ones replace the variable.
