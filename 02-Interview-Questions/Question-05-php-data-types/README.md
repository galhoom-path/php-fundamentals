## Interview Question

Which data types does PHP have?

## What The Interviewer Is Testing

Whether you can list and recognize the core value types and inspect them.

## A Strong Answer Should Cover

- Scalar types: `int`, `float`, `string`, and `bool`.
- Compound types: `array` (and objects, which are taught in the OOP repo), plus the special value `null`.
- `var_dump()` and `gettype()` show the type of a value at runtime.

## Practice Task

Write five values of different types and predict what `var_dump()` prints for each.
