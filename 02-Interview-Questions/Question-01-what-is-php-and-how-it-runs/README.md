## Interview Question

What is PHP, and how does it handle a web request?

## What The Interviewer Is Testing

Whether you understand server-side vs client-side execution and the request/response cycle, not only the name of the language.

## A Strong Answer Should Cover

- PHP is a server-side scripting language: the code runs on the server, not in the browser (unlike client-side JavaScript).
- Lifecycle: browser sends an HTTP request → web server (Apache, Nginx, or `php -S`) → if the target is `.php`, PHP runs → script may use stored data → PHP builds the response (usually HTML; also JSON/text) → browser renders it.
- A `.php` file can mix HTML and PHP; only the finished output is sent — the browser never sees the PHP source.
- PHP can also run from the CLI for scripts and tools; websites use the request/response path above.

## Practice Task

Explain, step by step, what happens from typing a URL to seeing a page generated by PHP. Include at least: find the server (DNS in one sentence), send an HTTP request, PHP runs on the server, response returns (often HTML), browser displays it.
