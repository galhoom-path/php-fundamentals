## Interview Question

What is PHP, and how does it handle a web request?

## What The Interviewer Is Testing

Whether you understand server-side execution and the request/response cycle, not only the name of the language.

## A Strong Answer Should Cover

- PHP is a server-side scripting language: the code runs on the server, not in the browser.
- The browser sends a request, the web server runs the PHP script, and the script produces a response (usually HTML).
- The browser only receives the output, never the PHP source code.

## Practice Task

Explain, step by step, what happens from typing a URL to seeing a page generated by PHP.
