## 🎯 Purpose

<br/>

PHP powers a large part of the web — from WordPress and Laravel to custom APIs and online stores. Every framework and every OOP concept sits on top of the same core language: variables, types, arrays, functions, and the request/response cycle. Skipping these basics is why many developers get stuck later.

<br/>

## 🔄 Staying Current

<br/>

> ♻️ **This is a living repo.** It always follows the latest stable PHP release.
> When a new version comes out (for example PHP 8.6), this same repo is updated: new features are added to the matching lectures,
> deprecated features are replaced, and completed lectures get a short catch-up session.
> The full procedure is in `template.md` Section 4.4.
